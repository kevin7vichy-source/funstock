# FUNSTOCK LIMITED & HARTHELM · 数字化交付与跨国商业架构系统

## 一、 项目概述与商业背景
本项目为 **FUNSTOCK LIMITED（趣仓有限公司）** 量身打造了一套零服务器成本、高安全隐私保护、支持中国境内与海外多端协同的轻量级低代码数字交付与管理生态。系统全面服务于企业的四地联动架构（内地制造、港澳贸易、新加坡海外桥头堡），涵盖出海跨境贸易、企业主资产管理与香港身份（高才/优才/专才）平稳续签的数字化实质证据链合规管理。

## 二、 系统架构与技术栈
* **前端交付**：Tailwind CSS (CDN 加载)、纯原生 JavaScript、**100% 零外部依赖的高清内联 SVG 矢量图标**（杜绝 CDN 阻断与裂图）。
* **后端与数据库**：Google Sheets (轻量级母表数据库) + Google Apps Script (GAS 自动化网关)。
* **文件云存储**：Google Drive 专属隔离目录 `HARTHELM_Vault`（只增不删，TLS 256位加密传输）。
* **隐私与安全**：完全符合香港《个人资料（私隐）条例》（PDPO）的 PICS 声明存证与 AES-256-GCM 客户端本地加密验证机制。

## 三、 7大核心页面与多语种架构
1. **出海独立官网/落地页**：品牌 VI 展示与“1+1 人机协同”出海服务推介。
2. **双端安全收件网关 (`intake_portal.html`)**：签约客户凭证上传与顾问员工工作台双端合一。
3. **私密客户加密看板 (`client_board.html`)**：依托 `data.js` 动态注入，向客户公示达成率、期末现金及顾问寄语。
4. **公司管理后台 v2.0 (`admin/index.html`)**：实控人内部运营作战室，抽屉式导航栏无缝切换。
5. **模块 1：经营计划与合规提醒引擎**：巡检 MPF 强积金供款及法定待办事项。
6. **模块 2：日常财务与四套账系统**：HK SME-FRS 准则下的利润表、资产负债表与总账平衡校验。
7. **模块 3：凭证沉淀与续签中心**：四维黄金证据链抓取，一键生成续签业务实质说明书底稿。
